# Computer Vision Homework Examples

This repository contains small, runnable Python examples for the image processing methods studied in class.

## Setup

```powershell
python -m pip install -r requirements.txt
```

## Run one example

```powershell
python examples/01_negative.py
```

Outputs are written to `outputs/`.

## Run all examples

```powershell
python examples/run_all.py
python application/red_object_detection.py
```
